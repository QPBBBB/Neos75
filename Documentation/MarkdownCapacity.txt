NEOS75 Markdown 容量规格（V04）
日期：2026-11-02

规格与口径
用户已接受单篇 UTF-8 Markdown 源文件最多 64 KiB（65536 字节，包含语法标记、空格和换行），并批准开发。
常用汉字通常占 3 字节，理论约 21845 字；混合格式正文的实际字数随内容变化。
这是产品支持上限，不是对硬件理论极限的承诺，也不表示所有复杂资源组合都能占满源文件额度。
有线与完全无线 2.4G 文档写入已跑通；64 KiB 的实机容量验收使用有线，无线本次实测为短文档。

已确认的原生内存配置
基准：Research/Screen/Backup20261102T084907Z/ScreenApplication.bin
SHA256：6dcaebdd012a6062d3d56c09a58d7bd3604d7564f9de08ca76d7162b5528291b
0x26490 的初始化代码：
  movw r0, #0xcf08
  movt r0, #0x8017
  mov.w r1, #0x60000
  bl 0x2c7d4
内存池起点 0x8017CF08，配置长度 0x60000=393216 字节=384 KiB。
池初始化扣除 0x6C8=1736 字节控制结构；391480 字节仍不是实机当前可用连续内存。
原生 label 文本会另行分配并复制 strlen+1 个字节，因此全文不能各自创建永久 label。

实际实现的资源限制
  UTF-8 源文件                     65536 字节
  编译后的结构化文档包            262144 字节（256 KiB）
  字形及图片掩码位图               98304 字节（96 KiB，计入文档包）
  字形记录                         6400 个
  排版行数                         32768 行
  单行字形                         512 个，且设备编码文本必须小于 4096 字节
  设备可见控件                     最多 24 行，单次文字更新预算 24 KiB
  图片                             单张高最多 160 像素，最多 8 色量化

便携 Python 在电脑解析 MD、排版并生成字形；设备收到的是行索引、字形记录、文字引用和掩码数据。
设备在 RAM 保留一份完整编译包，使用固定数量的原生 label 显示当前窗口，旋钮更新窗口起点。
不在设备长期保存原始 MD，也不把整篇文档生成为一张长图。
接收新文档前释放旧文档，不提供双文档原子切换；上传失败或分配失败时需重新上传。
384 KiB 预算中其余空间留给原生 UI、协议、可见文字及分配器；实际分配失败会回报错误。
超限明确报错，不静默截断。64 KiB 源文件若含大量不同字形或图片，仍可能先触及资源上限。

验证范围
已通过实际编译后的 ARM 指令级执行验证：65536 字节英文长段落、密集短段落、重复中文均能接收、校验和激活。
其中密集短段落编译包为 218542 字节、21846 行；65537 字节源文件在电脑端被拒绝。
实机也已完整接收该 65536 字节源文件：218542 字节包、21846 行，CRC32 提交成功且文档激活；约 59 秒完成上传。
随后通过主机滚动命令到达最后一行（零基行号 21845），再重新上传正常使用说明。
这些结果验证了约定的源文件容量及该排版负载，不能推断任意字形/图片组合都能占满额度，也不是硬件理论极限测量。
实机已确认中文、粗斜体、代码块、表格显示正常；用户正常打字未观察到卡顿。
这项现场确认不是按键输入延迟的仪器测量。

Flash 与恢复
设备代码规划占用 0x50000..0x54000 的四个 4 KiB payload 页，构建前严格核验原内容。
另有 Vector 0x8000、Information 0x35000、Hook 0x3C000 三页；安装时跳过已相同页面。
0x7F000 配置页与 Bootloader 不写入。用户文档接收不写 Flash，设备断电后恢复内置默认 Markdown；用户内容需要重新上传。
V06 默认 Markdown 包为 984 字节，随屏幕程序存于 16 KiB 扩展区；启动时复制到同一文档堆，首次上传即释放，不与最大用户文档叠加保留。
构建、安装与恢复说明见 ScreenUi.txt；使用方式见 ScreenMarkdown.md。

格式边界
支持标题、段落、粗斜体、删除线、代码、引用、嵌套列表、任务列表、表格、链接文字与有界图片。
宽表格改为逐单元格显示；HTML 仅静态文字/常用行内标签，公式与 Mermaid 按普通文字或代码显示。
远程图片需显式开启；不执行网页脚本或 CSS。字体来自本机 Windows 字体目录。
