原厂页面删除的实现范围
替换原厂初始化调用入口（原目标 0x117A0），因此不创建其页面对象，也不注册其页面刷新定时器。
只保留显示/USB/RTX/LVGL 与存储解码初始化；复用 LVGL 的初始空白 screen，创建三个自定义 label。
原 GUI 结构的七个页面指针均为零，状态接口实时读取这些指针计数。
原厂页面、菜单、主题、天气和时钟业务报文不再进入原业务解释器；只读信息查询保留。
原始 DFU 服务独立保留，可继续备份/恢复。
此处删除的是运行中的原厂页面构建、对象与事件链；仍复用原厂底层二进制库。
原厂镜像和资源归档保留用于恢复；未将整片原厂固件/外部资源 Flash 物理清空，也没有完整厂商 SDK。

屏幕代码
Code/Module/Screen/ScreenUi.c 是设备与 Windows 预览共用的控件代码。
CreateScreenUiOnScreen 在已有空白 screen 上创建标题、正文、状态控件。
SetScreenUiTitle、SetScreenUiMessage、SetScreenUiStatus 在 UI 线程动态更新文字。
Device/DeviceScreenUi.c 注册设备定时器，处理只读状态及原厂业务入口的移除。
Device/NativeLvgl.c/.h 桥接已核对的原生接口，未确认原厂完整 LVGL 版本。

写入顺序
Payload 0x50000 -> Vector 0x8000 -> Information 0x35000 -> Hook 0x3C000。
0x3C390 是自定义 UI 接入点；0x35064/0x353B2 接入业务包过滤和只读状态查询。
每页 4096 字节，逐页及完整应用区回读验证；不写 Bootloader。
0x7F000 配置页逐字节保留，包括自动回退时。
故障处理入口和 UI 超时保护返回 DFU；计数存放在自有 LVGL 堆对象，不借用原厂第二个协议标志字。
新状态锚点借用首个启动标志字；复位入口先清除锚点，原厂 DFU 标志仍保留其含义。
软件保护已做临时指令级验证，未在实机故意制造硬件异常。
